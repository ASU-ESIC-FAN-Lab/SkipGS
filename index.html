WRIVA multi-site: held-out test-view config comparison

Same three-way comparison deployed on JHU's WRIVA-Phase-2 pipeline (24-scene test set, per-scene 23k iterations, LoD-anchor Gaussian model). Each loop shows one held-out test view rendered by the final model of each configuration; scenes span outdoor architecture, camera-model challenges, environmental variation, transient objects, and dataset perturbations. FastGS + SkipGS keeps the pattern: ~-52% end-to-end training time vs. vanilla 3DGS at matched final render quality.

Each 6-second loop steps through the same test view rendered by Ground Truth → 3DGS Vanilla → +FastGS → +FastGS+SkipGS (1.5s each). Config-to-config visual differences are minor — the ~52% speedup does not degrade perceptual quality on WRIVA either.
